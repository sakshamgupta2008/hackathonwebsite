# HackVilla Udaipur

React + TypeScript + Vite website, with a lightweight real-time palace scene built in React Three Fiber.

## Run

```bash
npm install
npm run dev
```

Production build: `npm run build` (output in `dist/`). The supplied first background image is used on the hero; the second appears behind the Experience and Prizes sections. Both are optimized WebP assets with parchment overlays for text contrast and responsive cover positioning.
